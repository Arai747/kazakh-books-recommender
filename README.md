# BookRec — қазақ әдебиеті кітаптарын ұсыну жүйесі

ICT1103 · 2-аралық бақылау · топтық жоба. Негізгі тақырып — 7-апта, мәтінді өңдеу және TF-IDF; қосымша — 6-апта, кластерлеу.

## Мәселе және нәтиже

BookRec қазақ әдебиетіндегі кітаптарды іздеп, оқырман таңдаған кітаптарға ұқсас шығармаларды ұсынады. Интерфейсте кітап каталогы, іздеу, сүзгілер, таңдаулылар және ұсыныстар бар.

## Қазіргі репозиторий құрылымы

- `integrated-site/app.py` — негізгі Streamlit сайт.
- `integrated-site/recommender.py` — TF-IDF + Cosine Similarity.
- `integrated-site/database.py` — SQLite; `DATABASE_URL` берілсе PostgreSQL.
- `integrated-site/access_code.py` — жеке кодпен таңдаулыларды қалпына келтіру логикасы.
- `integrated-site/data/books.csv` — сайт қолданатын 270 кітаптық каталог.
- `integrated-site/covers/` — 270 SVG мұқаба.
- `integrated-site/theme.py` — сайт стилі.
- `books.csv`, `source_catalog.xlsx`, `build_catalog.py` — түбірдегі дерек файлдары және өңдеу скрипті.
- `synthetic_ratings.csv` — синтетикалық бағалар, нақты адамдардың деректері емес.
- `bookrec_testing.py` — 3 каталог мысалы, Precision@5, K-Means, ARI, silhouette.
- `test_bookrec_integration.py` — нақты сайттың ұсыныс модулі мен уақытша SQLite базасын тексеру.
- `PROJECT_REPORT.md`, `TEST_RESULTS.md`, `CONTRIBUTIONS.md`, `AI_DECLARATION.md`, `PRESENTATION_OUTLINE.md` — тапсыру материалдарының толтырылатын нұсқалары.

**Ескерту:** түбірдегі `app.py` — ескі интерфейс нұсқасы; толық Backend және жеке код бар сайт `integrated-site/app.py` арқылы іске қосылады. Екі нұсқаны шатастырмаңыз.

## Орнату және іске қосу

Python 3.10+ ұсынылады.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m streamlit run integrated-site/app.py
```

Streamlit әдетте `http://localhost:8501` ашады; порт бос болмаса басқа портты қолданады. Интернетке тұрақты жариялау бұл локальді команданың бөлігі емес.

SQLite әдепкіде `integrated-site/bookrec.db` файлын қолданады. PostgreSQL үшін құпия `DATABASE_URL` айнымалысын ортада немесе Streamlit Secrets ішінде орнатыңыз. **Құпия кілттерді GitHub-қа жүктемеңіз.** Supabase-ке нақты қосылу және басқа браузерден таңдаулыларды қалпына келтіру бөлек тексеріледі.

## Әдіс

Кітаптың атауы, авторы, жанры және бар болса сипаттамасы TF-IDF векторына айналады (`char_wb`, 2–5-граммалар). Таңдалған кітаптар векторларының орташасы пайдаланушы профилін құрайды. Cosine Similarity бойынша жақын, бұрын таңдалмаған кітаптар ұсынылады. Кластерлеу (K-Means) жеке `bookrec_testing.py` скриптінде бағаланады; сайттың негізгі ұсыныс модуліне кірмейді.

## Тексеру

```bash
python3 -m unittest -v test_bookrec_integration.py
python3 bookrec_testing.py
```

Екінші команда `bookrec_test_results/` қалтасына нақты нәтижелерді жазады. Оларды `TEST_RESULTS.md` ішіне енгізіңіз. Бұл тест скрипті сайттағы модульден бөлек TF-IDF baseline есептейді. Орындалмаған тест нәтижесін орындалды деп көрсетпеңіз.

## Дереккөздер, шектеулер және қауіпсіздік

Кітап сілтемелері мен дереккөз домендері CSV-дегі `read_url` және `source` бағандарында. Әр сілтеменің қолжетімділігі, басылым мәліметі және пайдалану шарттары түгел тексерілген жоқ. Көп кітапта мазмұн сипаттамасы бос; сондықтан ұсыныстар жанр, автор және атауға қатты тәуелді. Синтетикалық рейтингтер нақты оқырман сапасының дәлелі емес. Жеке кодты басқа адамдарға жарияламаңыз.

## Тапсыру

`PROJECT_REPORT.md` — есептің мазмұндық негізі; `PRESENTATION_OUTLINE.md` — 6 слайд жоспары (дайын .pptx емес); `CONTRIBUTIONS.md` — жеке үлес журналы; `AI_DECLARATION.md` — ЖИ декларациясы. Нақты авторларды, тест нәтижелерін және қорғау материалдарын команда өзі тексеріп толықтырады. Қорғау кезінде ЖИ қолдануға болмайды (AI-0).
