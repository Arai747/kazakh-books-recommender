# Қазақ кітаптарын ұсыну жүйесі (BookRec)

ICT1103, 2-аралық бақылау, топтық жоба. Негізгі тақырып: **7-апта, NLP (TF-IDF)**; қосымша: 6-апта (оқытушысыз оқыту, KMeans).

## Мәселе және пайдаланушы
Оқырманға өз талғамына сай келесі қазақ кітабын табу қиын. Сайт оқырманға ұнаған кітаптар тізімін алып, ұқсас, әлі оқылмаған кітаптарды ұсынады. Сапаны синтетикалық оқырмандарда Precision@10 және Hit@5 метрикаларымен тексереміз.

## Деректер (МАҢЫЗДЫ)
| Файл | Не | Шығу тегі |
|---|---|---|
| `data/source_catalog.xlsx` | команданың бастапқы тізімі: 272 кітап, 39 автор (атауы, авторы, жанры, бет саны, іздеу сілтемесі) | команда құрастырған **бастапқы іріктеу**; басылым/ISBN расталмаған (`edition_status` бағанында) |
| `data/books.csv` | `build_catalog.py` жасаған кесте; `genre_group` (5 топ) қосылған | Excel-ден автоматты түрде |
| `data/synthetic_ratings.csv` | 80 оқырманның 2400 бағасы | **СИНТЕТИКАЛЫҚ**, `generate_readers.py` жасайды (seed=42). Нақты адамдар мен жеке деректер жоқ |
| `data/synthetic_readers_truth.csv` | синтетикалық оқырмандардың жасырын сүйікті жанр топтары | тек бағалау үшін; нақты оқырманда мұндай дерек болмайды |

Жанр топтары (`genre_group`): роман/повесть/әңгіме (171), тарихи проза (38), мемуарлық проза (28), балалар прозасы (28), детектив (7). Топтау ережесі `build_catalog.py` ішінде.

Кітап сипаттамалары (`description`) әлі жоқ: бағанды команда толтырады. Дерек қоры тапсыру алдында нақты басылыммен (ISBN, баспа, жыл) расталуы тиіс. Файл атауында «300 кітап» делінген, бірақ ішінде 272 жол бар.

## Әдіс
1. Кітап мәтіні (атауы + автор + сипаттама + жанр) → TF-IDF. Негізгі нұсқа: символдық n-граммалар 2-5 (`char_wb`), себебі қазақ тілі жалғамалы, ал стеммерсіз әртүрлі жалғаулы сөздер сәйкеспейді. Балама: сөздік TF-IDF.
2. Оқырман профилі = ұнаған кітаптар (баға ≥ 4) векторларының орташасы.
3. Ұсыныс = косинустық ұқсастығы бойынша ең жақын, әлі оқылмаған кітаптар.
4. Каталогты кластерлеу: KMeans, k = жанр топтарының саны (5).

## Нәтижелер (`results/results.md` бойынша)
**Негізгі метрика: Precision@10.** Әр синтетикалық оқырманға 10 кітап ұсынылады; ұсыныстың қанша үлесі оның жасырын сүйікті жанр тобына түсетінін санаймыз (79 оқырман).

| Әдіс | Precision@10 |
|---|---|
| char TF-IDF + жанр (негізгі) | 0.720 |
| word TF-IDF + жанр | 0.720 |
| char TF-IDF жанрсыз | 0.638 |
| word TF-IDF жанрсыз | 0.637 |
| танымалдық | 0.282 |
| кездейсоқ таңдау | 0.247 |

**Қосымша: Hit@5 (leave-one-out).** Ұнаған бір кітап жасырылады, профиль қалғандарынан құрылады, 829 тест.

| Әдіс | Hit@5 |
|---|---|
| char TF-IDF + жанр | 0.048 |
| word TF-IDF + жанр | 0.042 |
| char / word жанрсыз | 0.048 / 0.045 |
| танымалдық | 0.028 |
| кездейсоқ таңдау | 0.018 |

Кластерлеу (char): жанр топтарымен ARI = 0.56, silhouette = 0.06 (жанрсыз ARI = 0.04).

TF-IDF сөздігі тек каталог мәтініне үйретіледі, оқырман бағалары оған түспейді. Үш мысал мен қате мысалы: `results/results.md`.

## Шектеулер (шынайы)
- Оқырмандар синтетикалық, талғам жанр топтарымен және 15 % шумен берілген. Precision@10 осы модельдік деректерде әдістің жанр тобын тауып жатқанын көрсетеді, нақты адамдардағы сапаны **көрсетпейді**. Бағалау жартылай дөңгелек: топтарды біз де синтезде, жүйе де мәтіндегі жанрдан табады.
- Hit@5 (жасырылған БІР кітапты табу) 272 кітапта өте қатал: 0.048, бірақ кездейсоқтан (0.018) шамамен 2.7 есе жоғары.
- Сипаттамалар жоқ, сондықтан ұқсастық негізінен автор, атау және жанр бойынша есептеледі. Нәтижесінде ұсыныстар бір автордың кітаптарына ауып кетеді (мысалы, Аймауытов). Сипаттамалар қосылса, сапа артуы тиіс.
- Каталог ішінде 9 атау қайталанады (әртүрлі авторлар), мысалы «Таңдамалы прозасы». Сайтта олар «Атауы — Автор» белгісімен ажыратылады.
- Жанр топтарының біреуі (роман, повесть, әңгіме) каталогтың 63 %-ын құрайды, ал детектив тек 7 кітап.
- Метод басқа оқырмандардың бағаларын қолданбайды (коллаборативті сүзгілеу жоқ).
